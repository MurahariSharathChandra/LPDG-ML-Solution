# AI Usage

AI assistance was used as a development partner for:

- turning the challenge requirements into a reproducible project structure;
- reviewing code for edge cases and deterministic output;
- suggesting tests and documentation structure;
- helping explain technical concepts while the project was being developed.

AI-generated suggestions were checked against the supplied challenge brief, data dictionary, FAQ, validator, and the actual dataset. Any result used in the final submission was reproduced locally from the supplied data.

## Verification

AI assistance was not treated as a source of ground truth. Model results, validation metrics, feature selection, prediction outputs and submission formatting were checked by running the project locally.

The final model and predictions were generated locally from the supplied challenge data, and the official submission validator was run successfully.

## Important limitation

AI assistance was used for development support and interpretation, but the final decisions were based on the supplied challenge materials, local data analysis, implemented code and locally reproduced results.
